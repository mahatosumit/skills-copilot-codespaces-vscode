# Contributing

## Development Loop

1. Inspect existing code.
2. Create or update a small plan.
3. Implement the smallest working change.
4. Add tests.
5. Run validation.
6. Update documentation.

## Validation

```bash
npm run validate
```

## Skill Import Rules

- Do not bulk-import external skill collections.
- Prefer metadata-first discovery.
- Review scripts and suspicious instructions before import.
- Keep curated packs small and verified.
